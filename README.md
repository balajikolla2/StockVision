> **StockVision AI** is a modular Python 3.13 application designed using Object-Oriented Programming (OOP) and layered architecture. 
> 
> **Key Features:**
> **Role-Based Access Control (RBAC)**: Distinct dashboards for **Administrators** (market inventory, pricing, user audit, system analytics) and **Investors** (wallet funding, stock trading, portfolio tracking).
> **Portfolio & ROI Analytics**: Calculates weighted cost basis, unrealized gain/loss, and net worth in real time.
> **Smart AI Recommendation Engine**: Tailors stock suggestions based on investor risk appetite, budget, and market performance metrics.
> **File Persistence**: Persistent data storage in pipe-delimited text files (`.txt`) with custom exception handling and SHA-256 password security.
